# Haven

Haven（代号"健健"）是面向患者的个人慢病管理智能体（Agent），帮助用户持续记录健康数据、理解变化趋势，并在可能存在风险时获得保守、清晰的就医提示。

当前版本：`0.0.1` · Python：`3.14+` · 状态：需求基线与项目骨架建设中

## 产品边界

- 面向慢病患者的长期日常管理，首个 MVP 聚焦高血压。
- 不是医疗诊断工具，不替代医生，也不提供个性化处方。
- **采用单一 Agent 架构**：Agent 自主感知→思考→决策→行动→记忆，而非传统 Web CRUD。
- 安全校验、数据验证和趋势计算优先使用确定性代码。
- 旧的通用多智能体、CLI REPL、飞书和守护进程架构不再属于当前产品方向。

## 首个 MVP（0.0.1）

```text
知情同意与建档 → Agent 引导录入血压 → 校验与二次确认 → 七日趋势 → 安全就医提示
```

首个 MVP 不包含自然语言数据抽取、用药提醒、完整知识问答、家庭协同或多智能体编排。
