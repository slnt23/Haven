# Haven

个人慢病管理智能体 — 你的长期健康伙伴。

面向已确诊慢病（高血压、糖尿病等）患者的 AI 陪伴型健康管理工具，聚焦 **长期陪伴**、**状态追踪** 与 **风险管理**。

## 理念

慢病管理的本质不是"看病"，而是长期行为改变与风险监控。Haven 做两件事：

- 在日常时刻里**陪伴与管理**，让你在门诊之外不再"无人管理"
- 在关键风险出现时**及时提醒**，引导线下就医

## 核心能力

| 健康画像 | 体征追踪     | 用药管理     | 症状记录 |
| -------- | ------------ | ------------ | -------- |
| 风险评估 | 生活方式干预 | 医学知识问答 | 情感支持 |
| 复诊随访 | 主动关怀     | 安全兜底     | 家庭协同 |

## 它不是

- ❌ 不是医疗诊断工具
- ❌ 不是在线问诊平台
- ❌ 不是通用 Chatbot

## 部署形态

**单租户**：一个 Haven 实例 = 一个用户，数据完全私有。

**软硬一体（远期）**：以语音交互终端的形式"陪伴在身边"，降低老年用户的使用门槛。
