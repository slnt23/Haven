## 设计原则

本项目采用 **Agent-First（智能体优先）** 的设计方法论：

```
定义 Agent → 反推能力 → 确定架构 → 选择技术栈
```

而不是传统的"先搭框架再填功能"的思路。这样做的好处是：

- 每一层架构都有明确的业务价值来源
- 避免过度设计（YAGNI）
- 技术栈服务于产品需求，而非反过来
