## 启动流程（系统装配）

```
┌─────────────────────────────────────────────────────────────┐
│  create_agent() — factory.py                                │
│                                                             │
│  1. AgentRuntime()          创建执行引擎                     │
│  2. _load_all_skills()      加载 haven.md + skills/*.md     │
│  3. runtime.init_llm()      创建 ChatDeepSeek/ChatOpenAI    │
│  4. _init_tools()           ToolManager + BuiltinProvider    │
│     ├─ BuiltinProvider      加载 web_search 等内置工具       │
│     └─ MCPProvider          加载 mcp.json 中的 MCP 工具      │
│  5. MiddlewarePipeline([    组装中间件管道                    │
│       PersonalityMiddleware  ← 注入 haven.md 人格            │
│       MemoryMiddleware       ← 四层记忆检索                   │
│       SummarizationMiddleware← Token 预算压缩                │
│       FilesystemMiddleware   ← 项目文件注入                   │
│       SkillsMiddleware       ← 领域 Skill 注入               │
│     ])                                                      │
│  6. PlannerAgent(runtime)   创建规划层                       │
└─────────────────────────────────────────────────────────────┘
```

## 四种执行模式

### 1. REPL 模式 (`haven` 或 `haven chat`)

```
用户输入 "帮我翻译一段话"
        │
        ▼
┌───────────────────┐
│ cli/main.py:main  │  Typer 入口
└──────┬────────────┘
       │
       ▼
┌───────────────────┐
│ chat.py:run_chat  │  创建 RuntimeService → create_agent()
└──────┬────────────┘
       │
       ▼  ┌──────────────────────────────────────┐
  REPL   │  每轮对话 _process_chat()              │
  循环   │                                        │
       │  │  chat_stream() → planner.execute_stream()
       │  │       │                                │
       │  │       ├─ plan() → _llm_plan()          │
       │  │       │   LLM 调用 #1:                  │
       │  │       │   with_structured_output        │
       │  │       │   → ExecutionPlan               │
       │  │       │   (意图 + Skill + 步骤)          │
       │  │       │                                │
       │  │       └─ 三条执行路径:                   │
       │  │          ├─ 简单对话 → runtime.astream() │
       │  │          ├─ 多步任务 → 拓扑排序 + 逐步执行│
       │  │          └─ 工作流   → graph.ainvoke()  │
       │  │                                        │
       │  │  runtime.astream() / run()              │
       │  │       │                                │
       │  │       ├─ _pipeline.before(state)        │
       │  │       │   PersonalityMiddleware         │
       │  │       │   → MemoryMiddleware (四路检索)  │
       │  │       │   → SummarizationMiddleware     │
       │  │       │   → FilesystemMiddleware        │
       │  │       │   → SkillsMiddleware            │
       │  │       │                                │
       │  │       ├─ create_react_agent(model,tools)│
       │  │       │   LLM 调用 #2: ReAct 执行        │
       │  │       │   (流式 or 非流式)               │
       │  │       │                                │
       │  │       └─ StreamRenderer 逐 token 输出   │
       │  │                                        │
       │  └─ save_turn() → 持久化                   │
       │     extract_facts_async() → LLM 调用 #3    │
       └──────────────────────────────────────────┘
```

### 2. 单任务模式 (`haven run --task "..."`)

```
haven run --task "搜索最新 AI 新闻"
        │
        ▼
┌──────────────────┐
│ run.py:run_task  │
│  → svc.start()   │  create_agent()
│  → svc.run_task()│
└──────┬───────────┘
       │
       ├─ 简单 / --no-plan → runtime.run() 直通
       │
       └─ 有规划:
          ├─ planner.plan() → ExecutionPlan
          └─ _execute_steps() → 逐步 runtime.run()
                 │
                 └─ 同 REPL 的 pipeline + ReAct 路径
```

### 3. 工作流模式 (`haven workflow run <name> --task "..."`)

```
haven workflow run dev_flow --task "写一个排序算法"
        │
        ▼
┌──────────────────────┐
│ workflow.py:run_workflow
│  → WorkflowRegistry.build(name)
│     → 编译后的 StateGraph
│  → svc.start()
│  → svc.run_workflow()
└──────┬───────────────┘
       │
       ▼
┌──────────────────────┐
│ graph.ainvoke(state) │  LangGraph DAG 执行
│                      │
│  planner → architect → coder → reviewer → tester
│     │          │         │         │         │
│     └──────────┴─────────┴─────────┴─────────┘
│            每个节点内部调用 runtime.run()
│            走完整的 pipeline + ReAct 路径
└──────────────────────┘
```

### 4. 守护进程模式 (`haven serve`)

```
haven serve
        │
        ▼
┌──────────────────────┐
│ HavenDaemon.start()  │
│  → create_agent()    │
│  → FeishuChannel()   │
│  → WsClient.start()  │  飞书 WebSocket 长连接
└──────┬───────────────┘
       │
       ▼  ┌──────────────────────────────┐
  消息事件 │  feishu_channel._handle_event │
  循环    │                               │
       │  │  解析消息 → planner.execute()  │
       │  │    ↓                          │
       │  │  runtime.run()                │
       │  │    ↓                          │
       │  │  中间件管道 + ReAct 执行        │
       │  │    ↓                          │
       │  │  飞书 API 回复消息              │
       └──└──────────────────────────────┘
```

## 核心机制

### 中间件管道执行顺序

```
AgentRuntime.run() / astream()
        │
        ▼
state = {"task": "...", "messages": [...], "system_prompt": "", "active_skills": [...]}
        │
        ▼
┌──────────────────────────┐
│ pipeline.before(state)   │
│                          │
│ 1. PersonalityMiddleware │  ← 注入 haven.md 人格 prompt 到 system_prompt
│ 2. MemoryMiddleware      │  ← MemoryManager.retrieve() 四路并行检索
│ 3. SummarizationMiddleware│ ← llm.get_num_tokens() 超限裁剪消息
│ 4. FilesystemMiddleware  │  ← 注入项目文件列表
│ 5. SkillsMiddleware      │  ← 从 state["active_skills"] 加载 skill prompt
└──────────────────────────┘
        │
        ▼
state["messages"].insert(0, SystemMessage(state["system_prompt"]))
        │
        ▼
create_react_agent(model, tools).ainvoke({"messages": final_messages})
        │
        ▼
LLM 响应
```

### 记忆系统（四层）

```
MemoryManager.retrieve(task="...")
        │
        ├─ WorkingMemory     ← 进程内 deque 滑动窗口，最近 20 条消息
        ├─ SemanticMemory    ← SQLite 实体-事实图 (memory_facts 表)
        ├─ EpisodicMemory    ← SQLite 完整对话记录 (episodes 表)
        └─ VectorMemory      ← ChromaDB 语义相似度搜索
        │
        ▼  asyncio.gather 并行执行
        │
        ▼
MemoryContext.format_for_prompt()
  → 注入 system_prompt
```

### LLM 调用次数

| # | 时机 | 位置 | 模型 | 目的 |
|---|------|------|------|------|
| 1 | 规划 | `planner.py:_llm_plan()` | 禁用 thinking 的 DeepSeek | `with_structured_output(ExecutionPlan)` |
| 2 | 执行 | `runtime.py:_get_agent()` | 完整 DeepSeek/OpenAI | `create_react_agent` → ReAct 工具调用循环 |
| 3 | 后台 | `manager.py:_extract_facts()` | 同上 | 从对话中提取语义事实 |

### 依赖关系

```
deepagents  ──→  中间件模式参考（未直接依赖其包）
langgraph   ──→  StateGraph, create_react_agent, MemorySaver
langchain   ──→  BaseChatModel, BaseMessage, BaseTool, ChatDeepSeek
pydantic    ──→  BaseModel (ExecutionPlan), BaseSettings (配置)
rich/typer  ──→  CLI 渲染
lark-oapi   ──→  飞书 SDK
chroma      ──→  VectorMemory 向量存储
```

## 学习路线

### 第一阶段：理解框架骨架

1. **入口 + 配置**（30 分钟）
   - `cli/main.py` — Typer CLI 入口
   - `config/settings.py` + `config/app.yaml` — 配置体系
   - `config/models.yaml` — 模型定义
   - 试运行：`uv run haven` 进入 REPL

2. **系统装配**（30 分钟）
   - `runtime/factory.py` — `create_agent()` 完整装配流程
   - 理解：Runtime → Skills → LLM → Tools → Middleware → Planner 的创建顺序

### 第二阶段：理解执行模型

3. **规划层**（45 分钟）
   - `runtime/planner.py` — `ExecutionPlan` Pydantic 模型
   - `_llm_plan()` — 一次 LLM 调用完成意图+技能+步骤+工作流
   - 三条路径：简单对话 / 多步编排 / 工作流 DAG

4. **执行引擎**（45 分钟）
   - `runtime/runtime.py` — `AgentRuntime` 类
   - `create_react_agent` 的用法
   - `run()` vs `astream()` 的区别
   - 中间件管道的集成点

### 第三阶段：理解上下文体系

5. **中间件管道**（1 小时）
   - `middleware/base.py` + `pipeline.py` — 基类和编排
   - `middleware/personality.py` — 系统人格注入
   - `middleware/skills.py` — 技能 prompt 注入
   - `middleware/memory.py` — 记忆检索注入（四路并行）
   - `middleware/summarization.py` — Token 预算控制
   - `middleware/filesystem.py` — 项目文件感知

6. **四层记忆**（1 小时）
   - `memory/manager.py` — `record_turn()` 和 `retrieve()` 编排
   - `memory/working.py` — 滑动窗口 + LLM 摘要
   - `memory/episodic.py` — SQLite 对话记录 + 时间衰减
   - `memory/semantic.py` — 实体-事实图 + 置信度衰减
   - `memory/vector.py` — ChromaDB 语义搜索

### 第四阶段：理解扩展系统

7. **Skill 系统**（30 分钟）
   - `skills/loader.py` — `.md` YAML frontmatter 解析
   - `skills/registry.py` — 注册表 + 依赖解析
   - 试写一个自定义 skill

8. **工具系统**（45 分钟）
   - `tools/manager.py` — `ToolManager` 提供者编排
   - `tools/resolver.py` — 五级工具匹配
   - `tools/web_search.py` — 内置工具示例
   - `tools/providers/builtin.py` + `mcp.py` — Provider 架构

9. **工作流引擎**（30 分钟）
   - `workflows/state.py` — TypedDict 状态定义
   - `workflows/graph.py` — `create_checkpointer()` 工厂
   - `workflows/graphs/dev.py` — 完整工作流示例

10. **守护进程 + 通道**（30 分钟）
    - `services/daemon.py` — `HavenDaemon` 生命周期
    - `services/feishu_channel.py` — 飞书 WebSocket 集成
