# Haven（健健）— 多智能体 AI 对话框架

## 项目概述

Haven 是一个基于 Python 的**多智能体 AI 对话框架**，支持多模型、多通道、长短期记忆、技能热加载与 MCP 协议集成。项目以动画《灵笼》中的医疗助手机器人"健健"为默认人格，提供 CLI 交互式对话、单次任务查询、守护进程三种运行模式。

## 技术栈

| 类别 | 技术 |
|------|------|
| 语言 | Python 3.14+ |
| LLM 框架 | LangChain + LangChain-DeepSeek + LangChain-OpenAI |
| 大模型 | DeepSeek V4、GPT-4o、Qwen Max 等，支持 OpenAI 兼容 API |
| 协议集成 | MCP（Model Context Protocol）多传输协议 |
| 消息通道 | TCP Socket、IMAP/SMTP 邮件、飞书 WebSocket 长连接 |
| 记忆存储 | SQLite（长期）+ collections.deque（短期）+ LLM 事实抽取 |
| RAG | OpenAI Embeddings + 自定义递归文本分割器 + 内存向量库 |
| 构建工具 | Hatchling + uv |

## 架构亮点

### 1. 多智能体编排与意图路由

系统包含 **5 个专业化智能体**（编导/编码/医疗/陪伴/实践），由 OrchestratorAgent 利用 LLM 进行意图分类后自动路由到对应专家。各智能体共享统一记忆层，但拥有独立的工具绑定与 LLM 实例，实现"独立推理 + 共享上下文"。

### 2. 零代码技能系统

领域知识与人格定义通过 **Markdown + YAML Frontmatter** 的 `.md` 文件实现。仅需将技能文件放入 `skills/` 目录即可自动发现、解析，并在触发关键词匹配时注入系统提示词。将"智能体知道什么"与"智能体如何运行"彻底解耦。

### 3. MCP 协议全集成

完整支持 Model Context Protocol 的三种传输方式（stdio / SSE / WebSocket），工具自动发现并分发到所有子智能体。外部工具通过 `mcp.json` 声明即可即插即用，单个服务故障自动降级。

### 4. 双层长期记忆

- **短期记忆**：基于 `deque` 的对话历史（最近 100 条）
- **长期记忆**：SQLite 持久化，每轮对话后 LLM 异步抽取结构化事实（姓名、偏好、健康信息等），附置信度评分，后续对话自动注入系统提示词，实现跨会话用户认知

### 5. RAG 检索引擎

自定义递归文本分割器（支持中英文标点智能断句）+ OpenAI Embeddings + 内存向量库。支持文件、目录、原始文本摄入，检索结果自动注入上下文。

### 6. 多通道守护进程

单进程同时服务三种通道（asyncio 并发）：
- **TCP Socket**：类 Telnet 交互式 REPL
- **Email**：IMAP 轮询收件 + SMTP 回复，支持白名单与去重
- **飞书**：WebSocket 长连接实时收发，支持 @ 提及与用户隔离记忆

基于 `BaseChannel` 抽象类可快速扩展 Discord / Telegram / WhatsApp 等新通道。

### 7. 配置分层与运行时切换

OmegaConf 深度合并实现 **内置默认 < 用户 YAML < 环境变量** 三层配置优先级。支持运行时 `/model` 切换模型，自动传播到所有子智能体并重新绑定工具。

## 项目价值

- **工程实践**：完整的 Python 异步框架设计，涵盖 CLI、守护进程、协议集成、数据库、信号处理等
- **架构设计**：多智能体编排、注册器模式、抽象通道、依赖注入、优雅降级
- **前沿技术**：MCP 协议落地实践、LLM 驱动的意图分类与记忆抽取、RAG 全链路实现
- **可扩展性**：新增智能体/工具/技能/通道均只需最少代码，遵循开放-封闭原则
