## 二、血压录入与校验

- [x] **F2.1 体征数据录入**
  - 0.0.3 仅交付血压手工录入（结构化表单 + 正则兜底："今天血压 135/85"）
  - 收缩压 60-300mmHg，舒张压 30-200mmHg
  - 输出：结构化体征记录（类型、数值、单位、时间戳）

- [x] **S3.2 结构化表单录入** — 体征录入表单，字段带实时校验

- [x] **S3.3 数据校验**
  - 数值范围、逻辑一致性（收缩压 > 舒张压）、格式正确性
  - 不能是未来时间
  - 校验失败返回易懂的错误提示

- [x] **F2.4 异常值标记**
  - 自动识别异常体征值：正常/偏高/偏低/严重异常
  - 阈值基于临床指南（血压 ≥140/90 为高血压，收缩压 >180 严重异常）

- [x] **S3.4 异常值二次确认**
  - 异常血压保存前显示数值、单位、时间供确认
  - "收缩压 200mmHg，这个数值偏高，确认无误吗？"
  - 拒绝后不产生体征记录

- [x] **US-025 重复提交幂等** — 同一请求重试不产生重复记录，返回原记录或冲突提示

- [x] **S4.2 异常检测** — 基于规则引擎检测异常体征值，纯规则计算，不依赖 LLM

## 四、安全兜底

### 紧急识别与响应

- [x] **F11.1 紧急关键词识别**
  - 实时识别：胸痛、剧烈头痛、呼吸困难、意识模糊、咳血、黑便、偏瘫等
  - 规则走版本化（D20 记录），源自有据可查的临床指南

- [x] **F11.2 紧急响应**
  - 触发后输出："请立即拨打 120 急救电话或前往最近医院急诊科。"
  - 不进行任何其他对话
  - 系统进入安全状态，只允许最小安全交互

- [x] **F5.6 紧急情况识别**
  - 经版本化安全规则识别紧急症状、体征组合或不确定高风险输入
  - 阈值注明指南来源、适用人群和测量条件
  - 使用含否定、转述、错别字和边界体征的测试集持续测量误报与漏报

### 安全过滤器

- [x] **S6.1 输入安全过滤**
  - 处理前安全扫描：紧急关键词、恶意输入、注入攻击
  - 疑似紧急进入安全状态机；恶意输入按类型拒绝或隔离
  - 规则记录来源、版本、适用地区和生效日期

- [x] **S6.2 输出安全过滤** — 输出前过滤诊断性表述、个性化用药建议、超范围建议

- [ ] **S6.3 范围边界控制** — 识别超出慢病管理范围的问题（急性病诊断、手术建议），引导就医

### 免责与合规

- [x] **F11.3 免责声明嵌入** — 知识问答结尾、风险评估结果后、就医建议后自动嵌入
- [ ] **F11.4 超出范围识别** — "我这是什么病"→引导就诊；"我应该吃什么药"→需医生制定
- [x] **F11.5 审计日志**
  - 最小化记录：时间戳、去标识主体 ID、事件类型、规则/模型版本、安全结果
  - D13 AuditLog 独立追加写，保留 ≥6 个月
- [x] **F11.7 用户数据删除** — 30 天内清除；备份按周期过期；依法保留数据去标识化

- [x] **S6.7 审计日志** — 同 F11.5，完整性校验方案另行设计
- [x] **S6.8 用户数据删除** — 同 F11.7
- [ ] **D16 SafetyEvent 写入** — 记录规则版本、触发原因、风险级别，不保存完整输入
- [ ] **D20 SafetyRuleVersion** — 规则摘要、适用地区、版本号、生效/失效日期

### 安全数据实体

- [x] **D13 AuditLog** — 独立追加写、保留 ≥6 个月
- [ ] **D16 SafetyEvent** — 不保存完整用户输入，记录规则版本以便回溯
- [ ] **D19 DataSubjectRequest** — 导出 30 天、删除 30 天
- [ ] **D20 SafetyRuleVersion** — 生效/失效日期明确，支持回滚

## 五、降级与容错

- [x] **S9.9 错误处理与降级**（在 0.0.2 基础上增强）
  - LLM 不可用：录入/校验/趋势不中断，返回预设安全回复
  - 记忆检索失败：仅用当前上下文
  - DB 不可用：返回友好错误，不谎报保存成功
  - 紧急判断失败：默认按紧急处理（保守策略）

- [ ] **NF2.2 故障恢复** — 崩溃后自动恢复（SQLite WAL），恢复 <5 分钟
- [x] **NF2.3 LLM 服务降级** — 不可用时返回预设安全回复，不返回空白或错误堆栈
- [x] **NF2.4 数据库容错** — 操作失败重试 3 次指数退避，降级返回友好错误

### 新增闭环基线

- [x] **B3 多轮确认闭环** — 异常二次确认为"可续接"状态流（用户回"确认"能接上）
- [x] **B5 LLM 降级矩阵** — LLM 不可用时录入/校验/趋势不中断；DB 不可用不谎报成功

## 八、用户故事

- [x] **US-003 每日血压记录**（P0）
  - "今天血压 135/85" 自然语言录入 + 表单录入
  - Agent 回复：当前值、与目标对比、简短评价。异常值（>180）触发二次确认
  - 验收：正常值保存成功；异常值二次确认通过后保存；拒绝不产生记录

- [x] **US-004 查看血压趋势**（P0）
  - 七日趋势总结：平均值、最高/最低、达标率、变化方向
  - 验收：有数据返回统计+解读；<3 条提示数据不足

- [x] **US-013 紧急情况响应**（P0）
  - "胸口疼得厉害"触发紧急响应，建议拨打 120
  - 否定句、转述和边界体征不因单关键词误判
  - 验收：紧急关键词触发安全状态机；否定句不触发；安全状态只接受最小交互

- [x] **US-021 数据隐私控制**（P0）
  - 查看隐私政策、导出健康数据（CSV）、请求删除（二次确认，30 天）
  - 验收：导出返回 CSV；删除后不可查询

- [ ] **US-022 识别超出范围的问题**（P0）
  - "我这是什么病"→"无法提供诊断"；"我应该吃什么药"→"需医生制定"
  - 验收：超范围问题被拒绝并给出引导

- [x] **US-023 非法体征输入**（P0）
  - 单位缺失、收缩压≤舒张压、未来时间、超范围值不直接入库
  - 验收：各非法输入被拒绝并提示修正

- [x] **US-024 异常值二次确认**（P0）
  - 异常血压保存前显示数值、单位、时间；拒绝不产生记录
  - 验收：确认->保存；拒绝->不产生记录；回"确认"能接上

- [x] **US-025 重复提交幂等**（P0）
  - 同一请求重试不产生重复记录
  - 验收：重复提交返回已有记录

- [x] **US-026 服务降级**（P0）
  - LLM 不可用不影响录入、校验、趋势；DB 不可用不宣称成功
  - 验收：LLM 故障时录入可用；DB 故障时返回明确错误

- [x] **US-028 紧急识别测试边界**（P0）
  - 覆盖明确症状、否定、转述、错别字、含糊描述和阈值边界
  - 分别报告误报与漏报
