## 二、血压录入与校验

- [x] **F2.1 体征数据录入**
  - 仅交付血压手工录入：由模型从自然语言中提取数值后调用工具（**无 Web 表单、无数值正则解析层**）
  - 收缩压 60-300mmHg，舒张压 30-200mmHg（固定单位 mmHg，无换算/单位输入）
  - 输出：血压记录（收缩压、舒张压、测量时间 `measured_at`；**无 type/unit 列**）

- [ ] **S3.2 结构化表单录入**（不适用）— 无 Web 表单；录入走对话 + 工具参数确定性校验

- [x] **S3.3 数据校验**
  - 数值范围、逻辑一致性（收缩压 > 舒张压）、格式正确性
  - 不能是未来时间
  - 校验失败返回易懂的错误提示

- [x] **F2.4 异常值分级**
  - 分级：正常 / 正常高值 / 1–3 级高血压 / 严重异常（**无「偏低」档**）
  - 阈值（`application/validation.py`）：收缩压 ≥140 或舒张压 ≥90 起为 1 级；**严重异常 = 收缩压 ≥220 或舒张压 ≥130**；二次确认触发线 = 2 级及以上（收缩压 ≥160 或舒张压 ≥100）

- [x] **S3.4 异常值二次确认**
  - 异常血压保存前显示数值与单位（固定文案不含时间）供确认
  - 实际模板（如 185/115）："您输入的血压值为 185/115 mmHg，这个数值偏高。确认无误吗？"（附 /confirm、/cancel 指引）
  - 拒绝后不产生体征记录

- [x] **US-025 重复提交幂等（1 分钟去重）** — 1 分钟内相同数值不重复保存，返回固定提示（**不返回原记录**）

- [x] **S4.2 异常检测** — 纯规则计算（`validation.py` 分级 + `is_abnormal` 落库），不依赖 LLM

## 四、安全兜底

### 紧急识别与响应

- [x] **F11.1 紧急关键词识别**
  - 实时识别：胸痛、剧烈头痛、呼吸困难、意识模糊、咳血、黑便、偏瘫等（确定性词表，`safety/emergency.py`）
  - 规则版本为代码常量（`storage/audit.py` 的 `RULE_VERSION`，随审计行记录）；**无 D20 规则版本表**；词表来源待补证据

- [x] **F11.2 紧急响应**
  - 触发后输出："请立即拨打 120 急救电话或前往最近医院急诊科。"
  - 不进行任何其他对话
  - 命中即整轮只输出固定 120 文案（不调模型、不执行工具、不追问）；**无持久安全状态**（逐条判定）

- [ ] **F5.6 紧急情况识别**（部分）
  - 已实现：确定性词表 + 否定/第三人称/假设模式（`safety/emergency.py`）
  - **未实现**：阈值指南来源标注、误报/漏报测试集（待补证据）

### 安全过滤器

- [x] **S6.1 输入安全过滤（部分）**
  - 已实现：紧急关键词 + 否定/转述/假设模式扫描（模型前拦截）
  - **无恶意输入/注入攻击扫描**；规则来源/地区未记录，版本见 `RULE_VERSION`

- [x] **S6.2 输出安全过滤** — `safety/output_filter.py`：诊断/处方句式整段替换；不含 XSS 过滤

- [ ] **S6.3 范围边界控制** — 识别超出慢病管理范围的问题（急性病诊断、手术建议），引导就医

### 免责与合规

## 八、用户故事

- [x] **US-003 每日血压记录**（P0）
  - "今天血压 135/85" 自然语言录入（无表单）
  - Agent 回复：数值 + 分级（无"与目标对比"）。异常值（2 级及以上：收缩压 ≥160 或舒张压 ≥100）触发二次确认
  - 验收：正常值保存成功；异常值二次确认通过后保存；拒绝不产生记录

- [x] **US-004 查看血压趋势**（P0）
  - 七日趋势总结：平均值、最高/最低、达标率、变化方向
  - 验收：有数据返回统计+解读；<3 条提示数据不足

- [x] **US-013 紧急情况响应**（P0）
  - "胸口疼得厉害"触发紧急响应，建议拨打 120
  - 否定句、转述和边界体征不因单关键词误判（SUSPICIOUS 走固定澄清文案）
  - 验收：紧急关键词触发固定 120 文案（无对话、无工具）；否定句不触发直出；无持久安全状态

- [ ] **US-021 数据隐私控制（部分）**（P0）
  - 已实现：查看政策 + 删除（中断门批准 + 即时删除）；**导出 CSV 未实现**
  - 验收：删除后不可查询；导出（待实现）

- [ ] **US-022 识别超出范围的问题**（P0）
  - "我这是什么病"→"无法提供诊断"；"我应该吃什么药"→"需医生制定"
  - 验收：超范围问题被拒绝并给出引导

- [x] **US-023 非法体征输入**（P0）
  - 收缩压≤舒张压、未来时间、超范围值不直接入库（固定单位 mmHg，无"单位缺失"检测）
  - 验收：各非法输入被拒绝并提示修正

- [x] **US-024 异常值二次确认**（P0）
  - 异常血压保存前显示数值与单位（不含时间）；拒绝不产生记录
  - 验收：确认->保存；拒绝->不产生记录；回"确认"能接上

- [x] **US-025 重复提交幂等（1 分钟去重）**（P0）
  - 同一数值 1 分钟内不重复保存
  - 验收：重复提交返回固定提示且不落库

- [ ] **US-026 服务降级（部分）**（P0）
  - 已实现：DB 故障返回明确错误、不宣称成功；**无 LLM 故障路径**（平台侧）
  - 验收：DB 故障时返回明确错误；（LLM 故障路径不可核对）

- [ ] **US-028 紧急识别测试边界**（未实现）
  - 无测试集与误报/漏报报告（待补证据）
