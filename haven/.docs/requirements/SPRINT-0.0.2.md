# Haven 0.0.2 需求文档 — 健康建档与 Agent 引擎

> **目标：Agent 决策循环跑通，用户能完成知情同意和高血建档。**
> 版本：0.0.2 · 状态：已确认 · 前提：0.0.1 已完成

---

## 0.0.2 交付目标

```text
隐私政策同意 → 引导建档（基本信息+疾病史）→ Agent 流式对话 → 画像确认
```

这是第一个有"Agent 感"的版本——用户不是填表单，而是在对话中被引导完成建档。

---

## 一、Agent 核心引擎（S9）★ 本版本中枢

```
用户输入 → S9.1 感知 → S9.2 思考 → S9.3 决策 → S9.4 行动 → S9.5 记忆
```

- [x] **S9.1 感知：输入解析与意图识别**
  - 安全扫描（最优先）→ 结构化数据提取（正则+LLM）→ 意图分类（规则优先+LLM兜底）
  - 意图类别：体征录入 / 建档引导 / 澄清确认 / 闲聊。延迟 <500ms，准确率 >90%

- [x] **S9.2 思考：上下文构建**
  - 组装：用户画像（S1.1）+ 对话历史（S1.3）+ 建档进度
  - 检索结果不超过 LLM 上下文窗口 60%

- [x] **S9.3 决策：多步推理与行动规划**
  - 决策类型：建档引导（追问下一项）、信息确认、澄清追问、紧急响应（框架预留）
  - 原则：安全优先 → 宁可多问不假设 → 确定性优先

- [x] **S9.4 行动：响应生成**
  - 通用场景 LLM 生成，流式输出 SSE 逐 token 返回
  - 安全场景预留预设模板入口

- [x] **S9.5 记忆：状态更新**
  - 异步更新不阻塞回复：新增数据写入画像/时间线、对话历史追加

- [x] **S9.6 多轮对话管理**
  - 维护：当前话题、待确认项、追问链。支持用户修正信息

- [x] **S9.7 流式响应** — SSE 逐 token 输出，首字延迟 <2s，速率 ≥20 tokens/s

- [x] **S9.9 错误处理与降级**
  - LLM 不可用：返回预设安全回复
  - 记忆检索失败：仅用当前上下文
  - DB 不可用：返回友好错误，不谎报成功

- [x] **S9.10 安全边界** — 所有 LLM 回复过安全过滤器；不做诊断性表述；不提供个性化用药建议

### Agent 闭环基线（本版本交付的）

| # | 机件 | 要求 |
| - | ---- | ---- |
| B1 | 会话级状态机 | 按用户/会话隔离，禁止全局单例共享状态 |
| B2 | 记忆注入上下文 | "思考"前读取用户画像注入决策上下文 |
| B3 | 多轮确认闭环 | 建档引导为"可续接"对话状态流 |
| B4 | 安全状态按用户隔离 | 紧急/降级只作用于当前用户 |
| B6 | 流式输出 | SSE 逐 token 输出 |

## 三、健康建档（F1）

- [x] **F1.1 基础信息采集**
  - 采集项：年龄（0-150）、性别、身高（50-250cm）、体重（2-500kg）、称呼（nickname ≤20字，可跳过）
  - 方式：Agent 引导式对话 → 逐项询问 → 确认汇总
  - nickname 是档案数据，不是身份（ADR-006 单租户模型）

- [x] **F1.2 疾病史记录**
  - 录入已确诊疾病：名称、确诊时间、严重程度（轻度/中度/重度）
  - 疾病名称支持 ICD-10 模糊匹配

- [x] **S1.3 对话记忆窗口** — 缓存最近 20 轮对话历史，超出自动摘要压缩
- [x] **S1.6 记忆检索** — 根据对话上下文检索用户画像、近期事件，延迟 <200ms
- [x] **S1.7 记忆更新** — 每轮对话结束后异步更新记忆
