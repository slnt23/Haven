## 状态约定

| 状态       | 含义                       |
| ---------- | -------------------------- |
| Proposed   | 方案已提出，待评审         |
| Accepted   | 通过评审，成为当前决策基线 |
| Deprecated | 被否决                     |
| Superseded | 被其他 ADR 取代            |

## 使用规则

- ADR 记录"为什么做这个决策"（背景、方案、权衡、后果），需求明细以 [requirements/](../requirements/) 为唯一来源。
- 已接受的 ADR 正文不可修改；如需变更，新增 ADR 并在旧文档标记 `Superseded by ADR-XXX`。
